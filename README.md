# Galagon

갤러그 스타일의 세로형 슈팅 게임 프로토타입입니다. Phaser 3 + Vite, 서버 없이 브라우저에서만 동작합니다.

## 실행 방법

```bash
npm install
npm run dev
```

브라우저에서 `http://localhost:5173` 접속.

## 조작법

- 이동: 방향키 또는 A/D
- 발사: Space (누르고 있으면 연사)
- 게임 오버 후 Space로 재시작

## 게임 규칙

- 적 편대가 화면 상단에 대형을 이루고 좌우로 흔들리며 대기합니다.
- 적이 주기적으로 대형을 이탈해 플레이어 쪽으로 급강하하며 총알을 발사합니다 (갤러그의 다이빙 공격).
- 급강하 중인 적을 맞히면 2배 점수를 얻습니다.
- 적 총알에 맞거나 적과 충돌하면 목숨을 잃습니다 (기본 3개).
- 모든 적을 처치하면 다음 웨이브로 진행하며, 웨이브가 올라갈수록 적의 급강하 빈도가 늘어납니다.
- 목숨을 모두 잃으면 게임 오버, 최종 점수가 표시됩니다.

## 파워업

적을 처치하면 18% 확률로 파워업 아이템이 떨어집니다. 플레이어와 겹치면 즉시 적용되고,
화면 우측 상단에 남은 시간이 표시됩니다.

| 아이템 | 효과 | 지속시간 |
|---|---|---|
| RAPID FIRE (노랑, 번개 표시) | 연사 속도 2.5배 | 8초 |
| SPREAD SHOT (초록, 부채꼴 표시) | 3방향으로 동시 발사 | 8초 |
| SHIELD (파랑, 고리 표시) | 모든 피격 무효화 (링 이펙트 표시) | 6초 |
